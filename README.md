# かんけん かんじ れんしゅう

漢検10級〜5級（小学校で習う1026字・2020年度からの学年別漢字配当表）の書き順・読み・かきとり練習アプリです。
HTML 1枚（`index.html`）で動作し、iPad + Apple Pencil での練習に対応しています。

公開URL: https://jyz002xyz.github.io/kanji-renshu/

## 主な機能
- 級ごとの漢字一覧、書き順アニメーション、読み・意味・熟語・部首の解説
- なぞりがき／おてほんなしの1画ずつの判定（書き順・向きのチェック）
- かきとりテスト、にがて漢字の復習
- アバター（キャラ）作成、ペンの色・太さ
- 記録のバックアップ（ファイル・ひきつぎコード）
